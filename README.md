# خدمة البريد المؤقت - مهمل

هذا المشروع هو نسخة مشابهة لموقع مهمل للبريد الإلكتروني المؤقت، يتيح للمستخدمين إنشاء عناوين بريد إلكتروني مؤقتة واستخدامها للتسجيل في المواقع والخدمات المختلفة دون الكشف عن بريدهم الشخصي.

## المميزات

- إنشاء بريد إلكتروني مؤقت عشوائي
- إنشاء بريد إلكتروني مؤقت مخصص
- استقبال الرسائل في صندوق الوارد
- تجديد صلاحية البريد المؤقت
- تغيير البريد المؤقت
- حذف البريد المؤقت
- واجهة مستخدم سهلة الاستخدام ومتجاوبة مع جميع أحجام الشاشات

## التقنيات المستخدمة

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS
- API Routes
- Cookies للتخزين المؤقت

## كيفية الاستخدام

1. قم بزيارة الموقع
2. اختر "إنشاء بريد عشوائي" أو "إنشاء بريد مخصص"
3. استخدم البريد المؤقت للتسجيل في المواقع أو الخدمات
4. انتقل إلى "صندوق الوارد" لمشاهدة الرسائل الواردة
5. يمكنك تجديد صلاحية البريد أو تغييره أو حذفه حسب الحاجة

## التشغيل محلياً

لتشغيل المشروع محلياً، اتبع الخطوات التالية:

```bash
# استنساخ المشروع
git clone https://github.com/Nafro-glitch/temp-mail-clone.git
cd temp-mail-clone

# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000) في متصفحك لمشاهدة الموقع.

## النشر

تم نشر هذا المشروع على Vercel. يمكنك نشر نسختك الخاصة باتباع الخطوات التالية:

1. قم بعمل fork للمشروع على GitHub
2. قم بتسجيل الدخول إلى [Vercel](https://vercel.com)
3. انقر على "New Project" واختر المستودع الخاص بك
4. اترك الإعدادات الافتراضية واضغط على "Deploy"
